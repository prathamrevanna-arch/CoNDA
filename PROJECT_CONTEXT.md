# CoNDA Frontend Module

CoNDA detects potential coordination between autonomous trading agents in a simulated DeFi market.

This repository contains only the frontend and demo module. Other team members' modules do not exist locally. Use mock data wherever required.

## Ownership

I own:
- frontend/
- demo/

Do not implement:
- backend detection mathematics
- simulator
- Solidity contracts
- backend routes
- blockchain infrastructure

## Frontend objective

Build a single-page live dashboard that shows:
- market prices
- observed price versus competitive counterfactual
- live coordination risk
- signal evidence
- agent activity
- case and challenge lifecycle
- scenario selection
- WebSocket connection state

Clarity is more important than feature count.
